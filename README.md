# OpenSupplyChain

> **Repositório:** `open-supply-chain-gov-data`

Uma plataforma end-to-end para automação de dados e KPIs de Supply Chain, construída com **dados públicos** (DataCo Smart Supply Chain dataset).

## Por que dados públicos?
- ✅ **Reprodutível:** Qualquer pessoa pode baixar os dados e rodar o projeto.
- ✅ **Transparente:** Sem dados proprietários ou confidenciais.
- ✅ **Acessível:** Não requer acesso a sistemas empresariais.
